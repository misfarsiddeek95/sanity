# Scentify Fragrances – Design System
Source: Scentify Brand Guidelines v1.0. Tagline: "Crafted to leave a lasting impression."

## Color (token → value → role)
| Token | Value | Role |
|---|---|---|
| ink / navy | #0A1128 | Primary dark: text, hero, footer, covers (~50% of a layout) |
| oud | #0E1630 | Deep navy surface variant |
| oud-2 / midnight | #1A1A2E | Panels and hover on navy |
| onyx | #12121A | Bottle black, premium dark accents |
| sand / ivory | #F5F0E8 | Light surfaces (~25%) |
| sand-2 / sand-3 | #E9E1D2 / #D6CBB4 | Alternate sections, borders |
| page background | #FBF9F4 | Body background |
| gold | #C8962E | Primary accent: buttons, rules (~15%, an accent not a surface) |
| gold-lt | #F2D06B | Gold on dark grounds, highlights |
| gold-dk | #8A6612 | Gold text on light (meets contrast) |
| mute | #5C5C66 | Secondary text |
| clay / jade | #9c3d2c / #1f5a4b | Functional only: sale/error, success |

## Typography
- Display / editorial: Cormorant Garamond (headings, hero, italics). Logo/brand labels: Cinzel (`font-cinzel`).
- UI / body: Montserrat 300–600. Buttons and labels uppercase, tracked 0.18–0.3em.

## Logo
Original artwork only, never redrawn or recoloured. Files in `public/brand/`:
- `scentify-lockup.png` – transparent, light surfaces (header)
- `scentify-navy.jpg` – original navy-silk artwork, dark surfaces (footer)
- `scentify-logo.png`, `scentify-emblem.png`, `scentify-wordmark.png`, `favicon.png`
Request vector (SVG/EPS) and transparent masters from the designer before print.

## Shape, motion
Sharp corners; arch motif (999px top radius) and zellige pattern kept as supporting texture. Motion restrained and reduced-motion safe.
